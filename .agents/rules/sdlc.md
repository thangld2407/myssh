# Quy Tắc Điều Phối SDLC Agents (Project-Level Only)

Dự án này áp dụng quy trình SDLC cục bộ với 7 vai trò:
1. `sdlc-product-analyst`: Phân tích PRD, User Stories, Gherkin criteria.
2. `sdlc-system-architect`: Kiến trúc kỹ thuật, C4 diagrams, ERD, API specs.
3. `sdlc-uiux-designer`: Tích hợp `ui-ux-pro-max-skill`, thiết kế Design System, Tokens, Wireframes, UX patterns.
4. `sdlc-software-engineer`: Clean code, SOLID, triển khai nghiệp vụ và UI components.
5. `sdlc-qa-engineer`: Unit & integration tests, boundary testing, edge cases.
6. `sdlc-security-auditor`: OWASP audit, secret scans, code smells.
7. `sdlc-devops-sre`: Docker multi-stage, CI/CD GitHub Actions, releases.

Mọi tài liệu, mã nguồn và kỹ năng (`ui-ux-pro-max`) chỉ tồn tại trong phạm vi dự án `MySSH`.
